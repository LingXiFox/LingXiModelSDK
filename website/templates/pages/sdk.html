LINGXI MODEL SDK / 2.0.0-ALPHA.1

十语言 SDK 与三入口接入文档

LingXiModelSDK 2.0 提供三条独立并行的接入路径：Model Catalog（零推理依赖）、Native Provider（直连原生协议）、Unified Provider（LMP 统一协议，不静默降级）。

1. Model Catalog

10 语言接口

读取 /models.json（Schema 2.0）。各语言的缓存、解析和查询覆盖见下表，目录可以独立使用。

2. Native Provider

核心协议 · Mock Tested

使用提供商原生请求体和响应直接通信，流式支持取决于语言和协议。

3. Unified Provider (LMP)

核心协议 · Mock Tested

使用 LMP 转换数据。按语言和协议核对工具调用、流式输出和推理状态的支持范围。

Swift、Go 和 TypeScript 调用示例

// Swift (Catalog + Unified)
import Foundation
import LingXiModelSDK
import LingXiProviderRegistry
import LingXiUnifiedProvider
let catalog = try await LingXiModelCatalog.load()
let client = UnifiedClient()
let resp = try await client.complete(
    protocol: .openaiChatCompletions,
    baseURL: "https://api.openai.com/v1",
    apiKey: ProcessInfo.processInfo.environment["OPENAI_API_KEY"],
    request: LmpRequest(model: "gpt-4o-mini", messages: [.init(role: "user", content: [.text("hi")])])
)

// Go (Native)
n := native.NewClient()
raw, err := n.OpenAIChatCompletions(ctx, native.RequestConfig{
    BaseURL: "https://api.openai.com/v1",
    APIKey: os.Getenv("OPENAI_API_KEY"),
}, map[string]any{"model": "gpt-4o-mini", "messages": []map[string]string{ {"role": "user", "content": "hello"} }})

// Go (Unified)
u := unified.NewClient()
out, err := u.Complete(ctx, native.ProtocolOpenAIResponses, "https://api.openai.com/v1", os.Getenv("OPENAI_API_KEY"), unified.Request{
    Model: "gpt-4o",
    Messages: []unified.Message{
        {Role: "user", Content: []unified.ContentBlock{ {Type: "text", Text: "hello"} }},
    },
})

// TypeScript (Node 20+, built package)
import { UnifiedClient } from "@lingxifox/model-sdk/unified";
const client = new UnifiedClient();
const res = await client.complete("cohere", "https://api.cohere.com", process.env.COHERE_API_KEY!, {
  model: "command-a-03-2025",
  messages: [{ role: "user", content: [{ type: "text", text: "hi" }] }],
});
