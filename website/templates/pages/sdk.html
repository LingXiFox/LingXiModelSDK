LINGXI MODEL SDK / 2.0 ROADMAP

多语言 SDK 与接入路径

LingXiModelSDK 2.0 提供三条并行且独立的接入路径，默认在调用方进程内直接完成通信与目录解析，不强制依赖任何中转服务。

1. Model Catalog

6 语言已实现

只读模型与提供商元数据查询。消费 /models.json，支持 ETag 条件请求、离线缓存、未知字段保留与确定性排序，无推理依赖、无需 API Key。

2. Native Provider

Phase 3 规划中

使用提供商原生请求体、响应与流式事件直接与上游通信，不强制经过统一抽象层。

3. Unified Provider

Phase 4 规划中

基于 LingXi Model Protocol (LMP) 的统一语义接口，显式暴露能力差异，禁止静默降级。可选配合独立 HTTP Gateway 使用。

Swift SDK（已发布 · 0.1.x）

仅依赖 Foundation，支持 macOS 13+、iOS 16+、tvOS 16+、watchOS 9+ 及 Swift 6 并发。

Swift Package Manager 安装

.package(
    url: "https://github.com/LingXiFox/LingXiModelSDK.git",
    from: "0.1.0"
)

目录查询示例

import LingXiModelSDK

let catalog = try await LingXiModelCatalog.load()
if let model = catalog.model(
    provider: "deepseek",
    id: "deepseek-v4-flash"
) {
    print(model.contextWindow as Any)
    print(model.pricing.input as Any)
}

let eligible = catalog.models(matching: ModelFilter(
    vision: true,
    minimumContextWindow: 200_000
))
