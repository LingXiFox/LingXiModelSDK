LINGXI MODEL SDK / 2.0.0-ALPHA.1

十语言 SDK 与三入口接入文档

LingXiModelSDK 2.0 提供三条独立并行的接入路径：Model Catalog（零推理依赖）、Native Provider（直连原生协议）、Unified Provider（LMP 统一协议，不静默降级）。

1. Model Catalog

10 语言已实现

消费 /models.json（Schema 2.0），支持 ETag 条件请求、离线缓存、三态语义与未知字段保留，零推理运行时依赖。

2. Native Provider

9 协议 · Mock Tested

使用提供商原生请求体、响应、流式事件与 SigV4 签名直接通信，保留全部原生扩展参数。

3. Unified Provider (LMP)

9 协议 · Mock Tested

统一消息、思考签名、工具调用、Prompt Cache、Embedding 与 Rerank；不支持的能力显式报错。

Swift / Rust / Go / TypeScript / Python 调用示例

// Swift (Catalog + Unified)
import LingXiModelSDK
import LingXiUnifiedProvider
let catalog = try await LingXiModelCatalog.load()
let client = UnifiedClient()
let resp = try await client.complete(
    protocol: .awsBedrock,
    baseURL: "https://bedrock-runtime.us-east-1.amazonaws.com",
    apiKey: ProcessInfo.processInfo.environment["AWS_CREDS"],
    request: LmpRequest(model: "anthropic.claude-3-5-sonnet", messages: [.init(role: "user", content: [.text("hi")])])
)

// Go (Unified)
u := unified.NewClient()
out, err := u.Complete(ctx, native.ProtocolOpenAIResponses, "https://api.openai.com/v1", os.Getenv("OPENAI_API_KEY"), unified.Request{
    Model: "gpt-4o",
    Messages: []unified.Message{
        {Role: "user", Content: []unified.ContentBlock{ {Type: "text", Text: "hello"} }},
    },
})

// TypeScript (Node 20+ / Browser)
import { UnifiedClient } from "@lingxifox/model-sdk/unified";
const client = new UnifiedClient();
const res = await client.complete("cohere", "https://api.cohere.com", process.env.COHERE_API_KEY!, {
  model: "command-a",
  messages: [{ role: "user", content: [{ type: "text", text: "hi" }] }],
});
