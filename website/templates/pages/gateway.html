LINGXI MODEL GATEWAY · OPTIONAL SUBSYSTEM

可选统一 HTTP Gateway 部署指南

LingXiModelSDK 默认在调用方进程内直连上游。需要集中鉴权、跨语言代理或统一审计时，可独立部署单二进制 Go Gateway。

默认安全策略（Fail-Closed）

  • 监听非回环地址时强制要求 -auth-token 与 -allow-hosts 出站白名单。
  • 拨号阶段校验解析 IP，阻断 RFC1918 私网、回环及云元数据地址（169.254.169.254）。
  • 上游请求禁用 HTTP 3xx 自动重定向，防止鉴权头泄漏。
  • 公共模型目录服务（models.lingxifox.cn）绝不接收任何推理正文或用户密钥。

HTTP API 端点

  • GET /v1/healthz：健康检查与注册表数量。
  • POST /v1/lmp/complete：统一非流式补全（9 协议）。
  • POST /v1/lmp/stream：逐帧实时 SSE 流式透传。
  • POST /v1/lmp/embed & POST /v1/lmp/rerank：向量与重排。
  • POST /v1/diagnostics/connect：端点解析与安全诊断。

构建与启动

cd gateway
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o lingxi-gateway .

# 本地回环开发模式
./lingxi-gateway -listen 127.0.0.1:8090 -registry ../registry/registry.json

# 生产内网/公网监听（强制鉴权 + 出站白名单）
./lingxi-gateway \
  -listen 0.0.0.0:8090 \
  -auth-token "$LINGXI_GATEWAY_TOKEN" \
  -allow-hosts "api.openai.com,api.anthropic.com,generativelanguage.googleapis.com" \
  -registry /etc/lingxi/registry.json
